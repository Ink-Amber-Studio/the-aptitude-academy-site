A guide for your editorial desk

Write. Review. Publish.

Everything you need to share a new field note, from the first draft to the finished article.

01

Create a post

1

Start with the story

Open Blog posts and choose New Blog post. Add a useful title, a short summary and the article text.

2

Make it clear

Use short paragraphs and headings. If you add a photo, describe what it shows in the image description field.

3

Review and publish

Use the preview to check the article. Save draft keeps it off the public site. Choose Publish when you are ready.

You decide when a post is ready. There is no separate content approval step. After publishing is connected, allow a few minutes for the website to update, then check the Field notes page.

Go to the editor  →
02

Use good images

  • Choose a real, relevant image that you have permission to use. A wide, clear photo works best for a cover.
  • Upload JPG, PNG, WebP or GIF images under 8 MB. Give the image a useful description, such as “Learners working together at a training table”.
  • Keep CVs, learner records, personal details and private documents out of this workspace. It is only for public marketing content.
03

If something does not work

  • Cannot sign in? Use the GitHub account invited to this workspace. Ask Ink & Amber to check access if it is not recognised.
  • Image will not upload? Check the file type and 8 MB size limit. Try a smaller JPG or PNG.
  • Post is not on the website yet? Check that you chose Publish, wait a few minutes and refresh the Field notes page. If it still does not appear, contact Ink & Amber with the post title. Your work should remain in the editor.
  • Need to change the main website? Send the wording or layout request to Ink & Amber. This workspace is for blog posts.
